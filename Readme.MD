**Перцептрон**

    [x] Имеет несколько входов со значением от 0 до 1.
    [x] Для каждого входа есть собственный вес.
    [x] Веса инициализируются случайными значениями.
    [x] Веса перемножаются с сигналами по формуле n1 * w1 + n2 * w2.
    [ ] Попадают в финкцию активации(могут быть разными).

    на выходе получаем сигнал от 0 до 1.
