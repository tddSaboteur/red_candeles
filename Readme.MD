 Вылазка №1 **Перцептрон**

    [x] Имеет несколько входов со значением от 0 до 1.
    [x] Для каждого входа есть собственный вес.
    [x] Веса инициализируются случайными значениями.
    [x] Веса перемножаются с сигналами по формуле n1 * w1 + n2 * w2.
    [x] Попадают в финкцию активации(могут быть разными).
    [x] на выходе получаем сигнал от 0 до 1.

    [x] Тестирование математики n1 * w1 + n2 * w2.

    [x] Реализовать метод корректировки весов.

        текущий вес += Ошибка *
                       скорость обучения *
                       производная функции активации взвененной суммы *
                       входящее значение. 
    [x] Реализовать производную функции активации RELU.
